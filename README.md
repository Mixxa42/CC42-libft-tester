# CC42-libft-tester
In the 42 Common Core : tester for the libft project.

## Test against official functions

Step 1:
```
git clone git@github.com:Mixxa42/CC42-libft-tester.git
```
```
cd CC42-libft-tester
```
Step 2:

Change LIBFT_PATH in the Makefile.

Step 3:

```
make re
```
```
./main_v5
```

## Test against values

cc main.c ft_test.h ft_test.c -I ../Common-Core---Libft -L ../Common-Core---Libft -lft
